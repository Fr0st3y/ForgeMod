ForgeMod 1.0 – cheat menu / trainer for The Witcher 3: Wild Hunt
by Fr0st3y
=====================================================================
(Deutsche Anleitung weiter unten.)

WHAT IS IT?
A standalone cheat menu for The Witcher 3 (single-player): god mode, money, XP,
all Gwent cards, item and creature galleries with in-game images, a world map
with click-to-teleport, weather, time and more – via buttons or hotkeys.
The interface is available in English and German (switch at the bottom left).

BESTIARY
All bestiary entries of the game with pictures, texts and weaknesses. By default only
the creatures you have already discovered (read from your newest save). Oils can be
applied and bombs/potions equipped with one click. "Open in separate window" shows
the bestiary in its own window, e.g. on a second monitor.

REQUIREMENTS
- Windows 10 or 11 (64-bit)
- The Witcher 3: Wild Hunt – Complete Edition / next-gen update (Steam, GOG or Epic)
- No other mods, no script merging, no installation.

INSTALLATION
1. Extract the "ForgeMod" folder anywhere (e.g. your desktop). Not into the game folder.
2. Start ForgeMod.exe.
   Windows SmartScreen may warn because the program is new and not code-signed:
   "More info" -> "Run anyway".

ONE-TIME SETUP (launch options)
ForgeMod uses the game's official debug interface. It is only active when the
game runs with the launch options:   -net -debugscripts
- Steam: Library -> right-click "The Witcher 3" -> Properties -> General ->
  Launch Options -> paste  -net -debugscripts
- Epic:  Library -> "..." on The Witcher 3 -> Manage -> Launch Arguments
- GOG Galaxy: The Witcher 3 -> settings icon -> Manage installation -> Configure ->
  Features -> Custom executables / arguments
ForgeMod shows these steps with a copy button under the gear icon (top right).
After that just start the game normally – ForgeMod detects it and unlocks the cheats.
Alternatively, the "Launch game" button starts the game with these options directly.

YOUR GAME STAYS VANILLA
ForgeMod does not change, add or delete any file in the game folder. It only reads
game files (names, icons, maps) to build its galleries, and reads your newest save
for the "Go to green waypoint" feature.

PRIVACY / OFFLINE
ForgeMod never connects to the internet and collects no data. The only network
connection is to the game itself on your own PC (127.0.0.1, port 37001).
Settings and image cache are stored in the "ForgeMod-Daten" folder next to
ForgeMod.exe – nothing is written to AppData or the registry.

UPDATING
Download the new version and replace the files of the ForgeMod folder.
Keep the "ForgeMod-Daten" folder if you want to keep your settings and hotkeys.

UNINSTALLING
Delete the ForgeMod folder. Optionally remove "-net -debugscripts" from the
launch options again.

ANTIVIRUS
ForgeMod is not code-signed (a certificate costs money every year), so some
antivirus programs do not know the file yet and may show a warning based on its
behaviour. ForgeMod starts no other programs in the background (only the game
itself when you click "Launch game") and registers its hotkeys only while the
game is connected.
Every upload is scanned by Nexus Mods via VirusTotal. If your antivirus reports
it, you can submit it to the vendor as a false positive.

WAS IST DAS?
Ein eigenständiges Cheat-Menü für The Witcher 3 (Einzelspieler): God Mode, Geld,
XP, alle Gwint-Karten, Galerien für Gegenstände und Kreaturen mit Bildern aus dem
Spiel, eine Weltkarte mit Klick-Teleport, Wetter, Uhrzeit und mehr – per Knopf
oder Hotkey. Die Oberfläche gibt es auf Deutsch und Englisch (unten links umschalten).

BESTIARIUM
Alle Bestiariums-Einträge des Spiels mit Bildern, Texten und Schwachstellen. Standardmäßig
nur die Kreaturen, die du schon entdeckt hast (aus deinem neuesten Spielstand). Öle lassen
sich mit einem Klick auftragen, Bomben und Tränke ausrüsten. "In eigenem Fenster öffnen"
zeigt das Bestiarium in einem eigenen Fenster, z. B. auf dem zweiten Monitor.

VORAUSSETZUNGEN
- Windows 10 oder 11 (64 Bit)
- The Witcher 3: Wild Hunt – Complete Edition / Next-Gen-Update (Steam, GOG oder Epic)
- Keine weiteren Mods, kein Script Merger, keine Installation.

INSTALLATION
1. Den Ordner "ForgeMod" irgendwohin entpacken (z. B. Desktop). Nicht in den Spielordner.
2. ForgeMod.exe starten.
   Windows SmartScreen warnt evtl., weil das Programm neu und nicht signiert ist:
   "Weitere Informationen" -> "Trotzdem ausführen".

EINMALIGE EINRICHTUNG (Startoptionen)
ForgeMod nutzt die offizielle Debug-Schnittstelle des Spiels. Sie ist nur aktiv,
wenn das Spiel mit diesen Startoptionen läuft:   -net -debugscripts
- Steam: Bibliothek -> Rechtsklick auf "The Witcher 3" -> Eigenschaften -> Allgemein ->
  Startoptionen -> -net -debugscripts einfügen
- Epic:  Bibliothek -> "..." bei The Witcher 3 -> Verwalten -> Startoptionen
- GOG Galaxy: The Witcher 3 -> Einstellungen-Symbol -> Installation verwalten ->
  Konfigurieren -> Funktionen -> Benutzerdefinierte ausführbare Dateien/Argumente
ForgeMod zeigt diese Schritte samt Kopieren-Knopf unter dem Zahnrad (oben rechts).
Danach das Spiel ganz normal starten – ForgeMod erkennt es und schaltet die Cheats frei.
Alternativ startet der Knopf "Spiel starten" das Spiel direkt mit diesen Optionen.

DEIN SPIEL BLEIBT VANILLA
ForgeMod ändert, ergänzt oder löscht keine Datei im Spielordner. Es liest nur
Spieldateien (Namen, Icons, Karten) für die Galerien und den neuesten Spielstand
für "Zum grünen Wegpunkt".

DATENSCHUTZ / OFFLINE
ForgeMod verbindet sich nie mit dem Internet und sammelt keine Daten. Die einzige
Netzwerkverbindung geht zum Spiel auf deinem eigenen PC (127.0.0.1, Port 37001).
Einstellungen und Bilder-Cache liegen im Ordner "ForgeMod-Daten" neben der
ForgeMod.exe – nichts landet in AppData oder der Registry.

AKTUALISIEREN
Neue Version herunterladen und die Dateien im ForgeMod-Ordner ersetzen.
Den Ordner "ForgeMod-Daten" behalten, dann bleiben Einstellungen und Hotkeys erhalten.

DEINSTALLIEREN

Startoptionen entfernen.

VIRENSCANNER

Jeder Upload wird von Nexus Mods über VirusTotal geprüft. Meldet dein Scanner etwas,
kannst du die Datei beim Hersteller als Fehlalarm einreichen.
